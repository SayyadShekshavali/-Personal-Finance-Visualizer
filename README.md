# 💸 Personal Finance Visualizer

A simple and responsive web application to **track personal finances**, view **monthly expenses**, and manage transactions with visual charts.

---

## 🚀 Features

- 🧾 Add / Edit / Delete Transactions
- 📊 Monthly Expenses Bar Chart (via Recharts)
- ⚡ Responsive Design 
- 💡 shadcn/ui
- 💾 MongoDB integration for persistent data
- 🧠 Built with Next.js and React

---

## 🛠️ Tech Stack

- **Frontend**: Next.js (React), shadcn/ui, Recharts
- **Backend**: Next.js API Routes
- **Database**: MongoDB (via MongoDB Atlas)
